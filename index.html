UI/UX · Case Study

Air Ticket Booking App

Reviewed and redesigned key screens of a flight booking application — search, seat selection, and checkout — with a focus on reducing drop-off at each step of the funnel.

Process

  • Research — mapped the existing user flow and flagged friction points in the original search-to-checkout journey.
  • Wireframes — restructured the seat-selection and passenger-details screens for clarity, in Figma.
  • Prototype — built an interactive click-through prototype to test the new flow before handoff.
  • Review — checked the delivered front-end build against the design spec and functional requirements, logging interaction and UX bugs (misaligned states, broken validation messages, inconsistent button behaviour) for the dev team to fix before launch.

UI/UX · Design System

Enterprise UI Component Library

Built a reusable component library in Figma for an enterprise web application, working within an agile team to keep every screen visually and functionally consistent before developer handoff.

Process

  • Audit — reviewed existing screens to find inconsistent buttons, inputs, and spacing across the product.
  • Build — created a shared library of reusable components (buttons, forms, cards, navigation) with defined states.
  • Validate — checked new screens against the library before handoff, catching mismatched components early.
  • Outcome — reduced rework caused by inconsistent components and sped up how quickly new screens could be designed.

QA · API Testing

Public REST API Test Suite

Target: reqres.in · Python, requests, pytest

What I did

  • Built 9 automated tests across GET, POST, PUT, and DELETE on a REST resource.
  • Validated status-code contracts, response schemas, and pagination behaviour.
  • Covered edge cases: invalid ID formats, empty payloads, non-existent resources.

Automation snippet

# Negative: nonexistent id should 404, not a misleading 200
def test_get_nonexistent_user_returns_404():
    response = requests.get(f"{BASE_URL}/users/9999", headers=HEADERS)
    assert response.status_code == 404

# Contract check: pagination fields always present
def test_users_list_pagination_contract():
    body = requests.get(f"{BASE_URL}/users?page=2", headers=HEADERS).json()
    for field in ("page", "per_page", "total", "data"):
        assert field in body
